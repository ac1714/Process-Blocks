# Simplify collection controls

## Builder rows and insertion

- Remove the Library, Build block, and Quick Add controls above and below individual cards, including the bottom of single-column rows.
- Show one insertion control group only after the final row in the collection.
- Insert anything chosen there into a new one-column row at the end by default.
- Remove the visible outer row frame and its row-level header so blocks are not enclosed by an extra container.
- Remove the separate “Add row below” action.

## Per-card controls

- Remove the Theme reset button from each card’s Accent controls while keeping the color choices.
- Move the 1–6 column selector onto the Accent line in each card. It will change the column count for the row containing that card.
- Keep block movement controls at the card’s bottom-right so blocks can move vertically or between the row’s columns.

## Custom block builder

- Remove the visible “Add part” and “Parts” labels while keeping the part-add buttons and ordered part list.
- Place the S, M, and L title-size controls on the same line as the Title label instead of below it.

## Header and panel

- Keep a clearly visible control for minimizing and restoring the left panel, with the panel state preserved while switching between Builder and Library.
- Restyle the Builder Save action as a neutral bordered control instead of the primary action color.

## Compatibility and validation

- Preserve existing saved collection layouts, block appearance settings, and exported standalone files.
- Verify end-only insertion, default one-column rows, column changes from a card, side-to-side movement, panel toggling, neutral Save styling, and the simplified custom block controls in the app and standalone export.
